# 🚀 Mini-Shell Test Suite | Project Epitech 2025

## 📌 Description

&emsp;This repository provides a functional test suite for the **Epitech Minishell1 project**\
&emsp;It automates command execution and compares results against the standard **Bash shell** to ensure correctness.

## 🎯 Usage / Examples

There are **two files** in this repository:

- **📄 test_cases.txt** → Where you put all the test cases you want to run.

- **🛠 run_tests.sh** → Executes the commands in ```test_cases.txt``` and checks if they work correctly.

## ➕ Adding New Tests

To add new test cases, simply edit ```test_cases.txt``` and add your commands:
```txt
ls -la
echo "Hello, World!"
pwd
```
Then, run the test suite:
```txt
./run_tests.sh
```
✅ The script will compare the output of your **Minishell1** with Bash and display the results.
