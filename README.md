# 🚀 Mini-Shell Test Suite | Project Epitech 2025

## 📌 Description

&emsp;This repository provides a functional test suite for the **Epitech Minishell1 project**\
&emsp;It automates command execution and compares results against the standard **Bash shell** to ensure correctness.

## Install

```sh
curl -sLO https://raw.githubusercontent.com/FloWindels/Mini_shell1_bash_tests/main/install.sh && bash install.sh
```
## Uninstall

```sh
sudo rm -rf /usr/local/bin/caillou
```
## Usage

✅ The script will compare the output of your **Minishell1** with TCSH and display the results.
To build the tests file, you can run
```sh
caillou
```
